# 🛒 E-commerce Sales & Customer Insights Dashboard

## 📌 Project Overview

This project analyzes e-commerce sales data to understand revenue performance, customer behavior, product category performance, regional sales and delivery-related customer ratings.

The analysis was performed using Python and Pandas, and the final dashboard was developed using Streamlit.

## 📊 Key KPIs

- Total Revenue: ₹5,109,775.74
- Total Orders: 5,000
- Total Customers: 989
- Average Order Value: ₹1,021.96
- Repeat Customer Rate: 96.06%

## 📈 Dashboard Features

- Monthly Revenue Trend
- Revenue by Product Category
- Revenue by Region
- Customer Segmentation
- Delivery Days vs Customer Rating
- Key business performance indicators

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- GitHub
- Google Colab

## 📂 Dataset

The dataset contains 5,000 e-commerce orders with information including:

- Order date
- Customer ID
- Product category
- Region
- Quantity
- Unit price
- Discount
- Payment method
- Delivery days
- Customer rating
- Revenue

## 🚀 Live Dashboard

The dashboard is deployed using Streamlit Community Cloud.

## 👩‍💻 Project Outcome

The project provides an interactive view of sales and customer data and helps identify patterns in revenue, categories, regions, customer segments and delivery performance.
